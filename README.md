# وين الحرف؟ — حروفي ٢

لعبة تعليمية مجانية في المتصفح للأطفال من **3 إلى 6 سنوات**.
تظهر صورة، وتحت الصورة **حروف منتشرة** — الطفل يختار أول حرف للكلمة
بشكله الصحيح في أول الكلمة (مثال: **سـ** وليس س).

- ✅ إجابة صح → علامة صح خضراء + نقطة + صورة جديدة بحرف مختلف
- ❌ إجابة غلط → الحرف يهتز وتقدر تجرب تاني
- ⏱ **دقيقة واحدة لكل صورة** — لو الوقت خلص: «الوقت خلص، حاول تاني»
- 🔇 بدون موسيقى — مؤثرات صوتية قصيرة فقط
- 📴 تشتغل **بدون إنترنت** بعد أول فتح
- 🔒 مفيش حسابات، مفيش إعلانات، مفيش تتبّع

## الحروف والكلمات

| الحرف | شكلـه في أول الكلمة | الكلمات |
|---|---|---|
| ر | ر | رُز 🍚 · رَاديو 📻 · رِجل 🦵 |
| س | سـ | سُكّر 🍬 · سَيّارة 🚗 · سِنجاب 🐿️ |
| خ | خـ | خُبز 🍞 · خَروف 🐑 · خِيار 🥒 |
| ن | نـ | نُجوم ⭐ · نَملة 🐜 · نِمر 🐆 |
| ت | تـ | تُفاح 🍎 · تَاج 👑 · تِمساح 🐊 |
| ل | لـ | لُعبة 🧸 · لَيمون 🍋 · لِسان 👅 |

> الراء من الحروف اللي مبتوصلش بالحرف اللي بعدها، عشان كده شكلها في أول الكلمة
> هو نفس شكلها منفصلة.

## التشغيل محليًا

```bash
cd letters-game-2
python -m http.server 8000
```

بعدها افتح <http://localhost:8000>.

> لازم سيرفر (مش فتح `index.html` بالدبل كليك) عشان الـ Service Worker يشتغل.


## ملاحظات تقنية

- **بدون مكتبات ولا build step** — HTML/CSS/JS خام.
- **المؤقت**: 60 ثانية لكل صورة، بيتوقف أثناء الاحتفال بالإجابة الصح، وبيتوقف
  لما التطبيق يروح للخلفية ويرجع (عشان الطفل ميتظلمش لو حد قفل الشاشة).
- **الكلام**: بيقول اسم الكلمة بالعربي عبر `speechSynthesis` (لو الجهاز فيه صوت عربي).
- **الأصوات** مولّدة بـ WebAudio — مفيش ملفات صوت ولا موسيقى.
