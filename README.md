# وين الحرف؟ — حروفي ٢

لعبة تعليمية مجانية في المتصفح للأطفال من **3 إلى 6 سنوات**.
تظهر صورة، وتحتها **حروف منتشرة** — الطفل يكوّن **الكلمة كلها** حرف ورا حرف،
وبيشوف الكلمة وهي بتتكتب بشكلها الصحيح (الحروف بتوصل ببعضها).

- ✅ كل حرف صح → بيدخل مكانه في الكلمة (والكلمة بتظهر بشكله الصحيح)
- 🎉 الكلمة كاملة → علامة صح خضراء + نقطة + صورة جديدة بحرف مختلف
- ❌ حرف غلط → الحرف يهتز وتقدر تجرب تاني
- ⏱ **دقيقة واحدة لكل كلمة** — لو الوقت خلص: «الوقت خلص، حاول تاني»
- 🔇 بدون موسيقى — مؤثرات صوتية قصيرة فقط
- 📴 تشتغل **بدون إنترنت** بعد أول فتح
- 🔒 مفيش حسابات، مفيش إعلانات، مفيش تتبّع

## الحروف والكلمات

كل كلمة بتظهر بحروفها بالترتيب، والطفل بيدوّر على الحرف اللي بعده.

| الحرف | الكلمات | الحروف |
|---|---|---|
| ر | رُز 🍚 · رَاديو 📻 · رِجل 🦵 | ر ز · ر ا د ي و · ر ج ل |
| س | سُكّر 🍬 · سَيّارة 🚗 · سِنجاب 🐿️ | س ك ر · س ي ا ر ة · س ن ج ا ب |
| خ | خُبز 🍞 · خَروف 🐑 · خِيار 🥒 | خ ب ز · خ ر و ف · خ ي ا ر |
| ن | نُجوم ⭐ · نَملة 🐜 · نِمر 🐆 | ن ج و م · ن م ل ة · ن م ر |
| ت | تُفاح 🍎 · تَاج 👑 · تِمساح 🐊 | ت ف ا ح · ت ا ج · ت م س ا ح |
| ل | لُعبة 🧸 · لَيمون 🍋 · لِسان 👅 | ل ع ب ة · ل ي م و ن · ل س ا ن |

> كل جولة بتظهر فيها حروف الكلمة + حرفين زيادة عشان الطفل يختار بينهم.

## التشغيل محليًا

```bash
cd letters-game-2
python -m http.server 8000
```

بعدها افتح <http://localhost:8000>.

> لازم سيرفر (مش فتح `index.html` بالدبل كليك) عشان الـ Service Worker يشتغل.

## ملاحظات تقنية

- **بدون مكتبات ولا build step** — HTML/CSS/JS خام.
- **المؤقت**: 60 ثانية لكل كلمة، بيتوقف أثناء الاحتفال بالإجابة الصح، وبيتوقف
  لما التطبيق يروح للخلفية ويرجع (عشان الطفل ميتظلمش لو حد قفل الشاشة).
- **الكلمة**: بتتقسم لحروف مع حركاتها، والكلمة بتتكتب حرف ورا حرف في شريط
  فاضي، فالطفل بيشوف الحروف وهي بتوصل ببعضها صح.
- **الكلام**: بيقول اسم الكلمة بالعربي عبر `speechSynthesis` (لو الجهاز فيه صوت عربي).
- **الأصوات** مولّدة بـ WebAudio — مفيش ملفات صوت ولا موسيقى.
